# 신규 환경 구성 참고용 초안 — 현재 제출 환경과 다름

이 코드는 사용자 작업 로그를 받기 전에 작성한 별도 신규 환경용 초안입니다.
현재 제출 환경은 사용자가 콘솔에서 만든 mission-vpc(10.0.0.0/16)와 Ubuntu EC2입니다.
이 초안은 10.30.0.0/16 및 Amazon Linux를 사용하며, 기존 리소스를 관리하거나 가져오지 않습니다.
현재 과제 진행에는 terraform apply/destroy를 실행하지 않습니다. 중복 리소스 생성 및 기존 환경과의 혼동을 피하세요.
이 초안의 검증·IAM 정책·배포는 완료되지 않았으며 제출 완료의 근거가 아닙니다.
