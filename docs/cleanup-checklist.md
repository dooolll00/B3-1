## 종료 전 확보한 근거

- [EBS 스토리지 화면](screenshots/13-ebs-before-cleanup-2026-10-09.png): 위 볼륨 ID·8 GiB·연결됨·종료 시 삭제=예 확인. 자동 삭제 설정은 실제 삭제 확인과 구분합니다.
- [무료 플랜](screenshots/10-free-tier-2026-10-09.png), [예상 청구서](screenshots/11-billing-summary-2026-10-09.png), [서비스별 내역](screenshots/12-billing-details-2026-10-09.png): 크레딧 적용과 현재 예상 청구액 확인. 월 최종 청구액은 미확정입니다.

EC2 종료 전에 EBS 볼륨 ID와 Delete on termination 설정을 기록합니다. EBS와 EIP는 인스턴스 Stop만으로 정리 완료가 되지 않습니다. 생성한 스냅샷이 있다면 별도로 추적합니다.

공유 자원이나 실습과 무관한 리소스는 삭제하지 않습니다. 조회 권한이 없어 목록을 볼 수 없다면 “없음”으로 처리하지 않고 담당 권한 소유자에게 확인을 받습니다. Billing의 과거 비용은 삭제 후에도 남을 수 있으며 화면에 비용이 없다고 모든 리소스가 정리됐다고 단정하지 않습니다.

증빙은 대상 ID·종료/삭제 상태·확인 시각을 기록합니다. 삭제한 리소스가 목록에서 사라진 화면은 리전과 필터도 함께 확인합니다.

## Internet Gateway 분리 및 삭제 과정

1. 실습 대상 `igw-00282b3ebdefbbd81 / mission-igw`를 확인하고 VPC에서 분리했습니다.
2. 첫 캡처의 분리 완료 배너, 상태 `Detached`, VPC ID `-`를 통해 연결 해제를 확인했습니다. 분리만으로 IGW가 삭제되는 것은 아닙니다.
3. 분리된 실습 IGW를 삭제하고 두 번째 캡처의 동일 ID 삭제 완료 배너를 확인했습니다.

삭제 후 목록에 남은 `igw-0bb4c1cb8483fbf59`는 다른 VPC에 연결된 별도 게이트웨이입니다. 이 실습 삭제 대상으로 처리하지 않습니다. 원본 파일명 시각은 분리 화면 20:08:42 KST, 삭제 화면 20:09:52 KST이며 실제 API 실행 시각은 별도 제공되지 않았습니다.

## 선택 후속 관리

- IAM 사용자·정책은 재사용 여부에 따라 불필요한 권한을 정리합니다. 현재 판단 대기이며 미션의 필수 과금 자원 삭제 항목은 아닙니다.
- 로컬 개인키는 저장소에 포함하지 않았으며 로컬 파일 삭제 여부는 별도입니다.
- Billing 반영 지연과 월 최종 청구 내역은 이후 다시 확인합니다.

## 추가 자원 생성 여부

2026-10-09 사용자는 이번 실습에서 NAT Gateway·로드 밸런서·RDS·스냅샷을 생성하지 않았다고 확인했습니다. NAT Gateway와 로드 밸런서는 이후 서울 리전 빈 목록 캡처로 잔여 자원 없음도 확인했습니다. RDS 및 EBS/RDS 스냅샷은 사용자 미생성 확인 기준이며 계정 전체 목록 직접 조회 결과는 아닙니다.
